# 多模态课程实验记录

使用 Qwen2.5-VL-3B-Instruct、4 位量化及本地 Gradio 界面。以下是实际运行的少量示例，不代表全面性能评测；截图保留模型的原始输出，包括错误。

1. **OCR**：自制虚构票据，日期、单价、数量和合计均被读出。[截图](images/ocr.jpg)
2. **图片阅读理解**：就同一票据询问单价、数量和合计；模型回答 12 元、3 件、合计 36 元，计算正确。[截图](images/reading.jpg)
3. **视觉定位**：要求定位“合计：36 元”，界面将模型输入坐标换算至原图后绘制绿色框。[截图](images/grounding.jpg)
4. **风景识别**：使用国会图书馆的优胜美地山谷照片，模型识别出 Yosemite Valley。[截图](images/scenery.jpg)
5. **公众人物识别**：使用白宫官方人物照片，模型认出了唐纳德·特朗普，但错误描述其有浓密胡须，说明识别结果及附带描述都需核对。[截图](images/public-figure.jpg)
6. **视频事件定位**：对 20 秒的开放许可动画片段询问兔子出洞和伸展时间。直接输入视频时模型两次给出错误时间；后来将 8 个抽样帧及其原视频时间一并提供，模型回答 5.0–17.5 秒，覆盖了人工查看到的动作，但区间较宽。[改进后截图](images/video.jpg)
7. **医学影像微调**：在公开 PneumoniaMNIST 儿童胸片数据上训练 QLoRA。演示样例真实标签为肺炎，但模型预测正常；测试集子样本准确率为 50.0%，肺炎召回率为 37.5%。[截图](images/medical.jpg) · [完整实验记录](../reports/README.md)
